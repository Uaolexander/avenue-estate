Не пиши довгих технічних простирадл у відповідях — покажи результат, а не лекцію. Якщо її прохання суперечить хорошому UX/дизайну або технічно дивне — скажи прямо і запропонуй кращий варіант, не виконуй сліпо.

## Дизайн-напрям, який схвалила Діана

Референс змінився з estatepoint.pl на «кінематографічні» сайти нерухомості з
TikTok (ICG Gallery, Atelier Lacroix, Nomada / «Composed Spaces»): камера ніби
їде крізь приміщення, поки гортаєш, а поверх лежить великий напис.

Реалізовано в `src/sections/Hero.jsx` + хук `useScrollScene` у `src/hooks.jsx`:
висока секція `.hero-scene`, всередині «липкий» екран, кадри інтерʼєру
перетікають один в одного й наближаються за прогресом прокрутки. Справжнього 3D
немає — це послідовність фотографій, і для повного ефекту потрібне відео або
рендер-послідовність.

Чого Діана НЕ хоче (перевірено на практиці):
- секції, що наїжджають одна на одну заокругленими кутами — виглядало погано;
- різкі, швидкі переходи. Анімації мають бути повільні й плавні;
- білий текст — замість нього фірмовий бежевий `#d4bea0`.

## Тести

`playwright` встановлено окремо (не в залежностях проєкту). Перевірки ганяються проти
`npm run dev` і покривають те, що вже ламалось: биті картинки, самовільна прокрутка
сторінки, стрічка оферт, перемикання мов, меню, форма, поведінка на телефоні.
Будь-яку зміну в інтерактиві варто проганяти через них — Діана не зможе продіагностувати
поламану сторінку, вона побачить лише симптом.

## Технічний стек і команди

React 18 + Vite, react-router-dom (HashRouter), звичайний CSS (без Tailwind), свій i18n без бібліотек.

```bash
npm install       # перший запуск
npm run dev       # локальний сервер, http://localhost:5173
npm run build     # прод-збірка в dist/
npm run sync      # вручну підтягнути свіжі оферти з Telegram-каналу
```

## Карта файлів

- `src/i18n.jsx` — УВЕСЬ текст сайту трьома мовами (одне місце для правок текстів)

- `src/sections/*.jsx` — кожен блок сайту окремим файлом (Hero, About, PropertiesHome, Services, Team, Career, Contact, Footer)
- `src/pages/Home.jsx`, `src/pages/Offers.jsx` — дві сторінки сайту
- `src/styles/global.css` — всі стилі й кольори (CSS-змінні на самому початку файлу)
- `src/assets/` — картинки/лого від Діани
- `scripts/fetch-telegram.mjs` — парсер Telegram-каналу
- `.github/workflows/` — автодеплой і автосинк офертів
